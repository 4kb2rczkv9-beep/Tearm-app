## 프로토타입 보는 방법

아이폰 Safari에서 위 주소를 열면 앱처럼 바로 눌러 볼 수 있습니다. 홈 화면에 추가하면 전체 화면으로 열립니다(Safari 공유 → 홈 화면에 추가).

홈은 「집 + 차 모드」입니다 — 위쪽 전환 칩에서 `🏠 우리 집`과 `🚗 내 차`를 오갈 수 있고, 신호등 요약·1줄 배너·그림은 지금 보는 모드의 품목만 셉니다. 선택하지 않은 쪽 칩에는 그쪽의 🔴 급한 개수가 작게 붙습니다. 차 모드는 보닛과 루프를 열어 그린 차량 도해 위에 **실내 · 외부 · 엔진룸** 3구역 뱃지가 붙고, 집과 똑같이 누르면 그 구역의 소모품 목록이 열립니다.

- **집 타입 3종**: 평면도 우측 상단의 `🏠 34평 ⌄` 칩이나 `설정 → 우리 집 평면도`에서 원룸/오피스텔 · 투룸/신혼집 · 34평 아파트를 고르면 즉시 바뀝니다. 생필품은 공간(욕실·주방·방·거실)에 묶여 있어 집 타입을 바꿔도 알맞은 구역으로 따라갑니다.
- **방·구역 뱃지**: `방이름 5개` / `🔴1 🟡3 🟢1` 두 줄만 보여 줍니다(0개인 색은 생략). 교체 완료를 누르면 뱃지 숫자와 상단 신호등 요약이 바로 갱신됩니다.
- **방·구역 이름 바꾸기**: `설정`에서 방 이름과 차량 구역 이름(실내·외부·엔진룸 → 모터룸 등)을 8자까지 바꿀 수 있습니다.
- **내 차 켜기/끄기**: `설정 → 내 차`의 스위치와 차량 이름(별명, 8자). 끄면 홈의 🚗 칩·차 모드·추천 목록의 차 소모품이 숨겨지고, 등록한 차 품목과 이력은 지워지지 않아 다시 켜면 그대로 돌아옵니다.
- **+ 추가 → 추천 목록에서 고르기**: 욕실·주방·거실/가전·침실/세탁·아기방·내 차 **37종**을 구역·기본 주기와 함께 보여 주고, 한 번 누르면 주기·알림 시점까지 자동으로 등록됩니다. `🧼 청소·빨래` 칩으로 세탁조 청소·침구 세탁·배수구 거름망만 모아 볼 수 있습니다.
- **홈 초기 데이터**: 집 15개(세탁조 청소·침구 세탁·이불 세탁 포함) + 차 6개. 선택한 집 타입·방 이름·차량 설정은 브라우저(localStorage `tearm.v9`, 이전 `tearm.v7`도 읽음)에 저장돼 새로 고쳐도 유지됩니다.

> 프로토타입은 화면과 동작을 확인하기 위한 정적 데모입니다. 실제 알림 발송과 가족 간 동기화는 기획서 5장의 스택(Expo + Supabase)으로 구현합니다.
