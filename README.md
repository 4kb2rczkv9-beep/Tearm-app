# 텀 (Tearm)

우리 집 생필품의 **교체할 날**을 가족이 함께 기억해 주는 앱 — 기획서와 화면 프로토타입입니다.

## 바로 보기

- **프로토타입 (아이폰 Safari)**: https://4kb2rczkv9-beep.github.io/Tearm-app/
- **기획서 (PRD v0.1)**: [docs/PRD.md](docs/PRD.md)

## 이 저장소에 있는 것

| 파일 | 내용 |
| --- | --- |
| `index.html` | 생필품 교체 알림 앱 화면 프로토타입 (HTML 한 파일, 서버·설치 필요 없음) |
| `docs/PRD.md` | 기획서 v0.1 — 문제 정의, MVP 범위, 화면 구성, 데이터 구조, 기술 스택, 일정·비용 |

## 프로토타입 보는 방법

아이폰 Safari에서 위 주소를 열면 앱처럼 바로 눌러 볼 수 있습니다. 홈 화면에 추가하면 전체 화면으로 열립니다(Safari 공유 → 홈 화면에 추가).

> 프로토타입은 화면과 동작을 확인하기 위한 정적 데모입니다. 실제 알림 발송과 가족 간 동기화는 기획서 5장의 스택(Expo + Supabase)으로 구현합니다.
