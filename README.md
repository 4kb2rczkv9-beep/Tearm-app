## 프로토타입 보는 방법

아이폰 Safari에서 위 주소를 열면 앱처럼 바로 눌러 볼 수 있습니다. 홈 화면에 추가하면 전체 화면으로 열립니다(Safari 공유 → 홈 화면에 추가).

홈은 「집 타입별 3D 평면도형(v7)」입니다 — 한 장의 3D 아이소메트릭 평면도 위에서 방 구역을 직접 누르면 그 공간의 생필품 리스트가 열립니다. 각 방 위에는 방 이름·개수 라벨과 지금 바꿀 물건 말풍선이 떠 있고, 교체 완료를 누르면 말풍선과 신호등 요약이 바로 갱신됩니다.

- **집 타입 3종**: 평면도 우측 상단의 `🏠 34평 ⌄` 칩이나 `설정 → 우리 집 평면도`에서 원룸/오피스텔 · 투룸/신혼집 · 34평 아파트를 고르면 즉시 바뀝니다. 생필품은 공간(욕실·주방·방·거실)에 묶여 있어 집 타입을 바꿔도 알맞은 구역으로 따라가고, 원룸처럼 방이 하나인 집에서는 방 물건이 거실/침실로 모입니다.
- **방 이름 바꾸기**: `설정 → 방 이름 바꾸기`에서 아기방을 서재·드레스룸·작업실 등으로 바꾸면 평면도 라벨·리스트·상세의 공간 이름이 함께 바뀝니다.
- 선택한 집 타입과 방 이름은 브라우저(localStorage)에 저장돼 새로 고쳐도 유지되고, 설정의 `평면도·방 이름 처음으로`로 되돌릴 수 있습니다.

> 프로토타입은 화면과 동작을 확인하기 위한 정적 데모입니다. 실제 알림 발송과 가족 간 동기화는 기획서 5장의 스택(Expo + Supabase)으로 구현합니다.
